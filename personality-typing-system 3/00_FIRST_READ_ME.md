## ❓ Häufige Fragen

**Q: Was ist, wenn ich einen Fehler mache?**
A: Kein Problem! Du kannst jederzeit neuen Code pushen:
```bash

git commit -m "Fix: whatever"
git push
```

**Q: Kann ich den Code ändern?**
A: Ja! Mach Änderungen lokal, commit, push.

**Q: Wie lade ich Contributors ein?**
A: Settings → Collaborators → Add people

**Q: Was ist mit SSH vs HTTPS?**
A: HTTPS ist einfacher (copy-paste). SSH ist sicherer (SSH Key nötig).
